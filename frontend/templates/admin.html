Oracle PL/SQL Enterprise Database Architecture

This system was designed with 100% compliant Oracle PL/SQL specifications located in database/plsql/.

Automated Triggers

  • trg_users_calc_bmi - Auto computes BMI & WHO category on member insert/update.
  • trg_order_items_reduce_stock - Decrements product stock quantity on store purchases.
  • trg_sub_audit - Logs all subscription creation and extensions into audit_logs.

Stored Procedures

  • sp_register_user - Handles encrypted member onboarding.
  • sp_subscribe_user - Manages Student, Couple, and Standard plans.
  • sp_admin_extend_subscription - Extends days and recalibrates expiry.
  • sp_place_order - Line-item order processing and stock checks.

Package & Functions

  • pkg_gym_management - Enterprise package specification & body.
  • fn_calculate_days_remaining - Returns integer countdown days.
  • fn_format_time_left - Returns formatted countdown string.

Oracle DB Connectivity

oracle_connector.py is configured using python-oracledb. To switch this server directly to Oracle XE or Oracle Cloud ATP, set USE_ORACLE = True in config.py.
